# MGS.Cacher

# Summary
- Cacher for data.

## Ability

- Cacher.
- TimeoutCacher.

## Install

- Unity --> Window --> Package Manager --> "+" --> Add package from git URL...

  ```text
  https://github.com/mogoson/MGS.Cacher.git?path=/Assets
  ```

# Usage
- Create instance of the class Cacher<T> or TimeoutCacher<T>
- Set cache with key and value.
- Get cache by key.
